# テクニカルサポート業務日報システム

業務委託メンバーが日報を入力し、Google スプレッドシートにデータを蓄積。指定日のデータを別紙6様式のPDFとして出力するシステム。

## 構成

| ファイル | 内容 | 配置場所 |
|---|---|---|
| `index.html` | 日報入力フォーム | GitHub Pages で公開 |
| `gas_code.js` | doPost: フォーム→スプレッドシート | 閲覧用スプレッドシート（CCBT業務完了報告 2026）の Apps Script |
| `gas_code_admin.js` | PDF生成 + 割り振り台帳の管理 | 管理用スプレッドシート（CCBTテクニカル業務 実績管理 2026）の Apps Script |
| `日報ヘッダー.csv` | スプレッドシートのヘッダー行 | — |

## フォーム URL

https://itoyuya.github.io/daily-report2026/

## セットアップ手順

### 1. Google スプレッドシート

1. 新規スプレッドシートを作成
2. `日報ヘッダー.csv` をインポート
3. シート名を「日報」に変更

### 2. Google Apps Script

1. スプレッドシートの「拡張機能 → Apps Script」を開く
2. `gas_code.js` の内容を貼り付け
3. `CONFIG` の `DRIVE_FOLDER_ID` を保存先フォルダのIDに設定
4. デプロイ → ウェブアプリ（実行: 自分、アクセス: 全員）
5. 発行されたURLを `index.html` の `GAS_URL` に設定して push

### 3. PDF 生成

管理用スプレッドシート（CCBTテクニカル業務 実績管理 2026）のメニューから実行する。

#### 日次PDF（メニュー: 日報PDF → 日次PDF出力）
- 「設定」シート B1 セルに `YYYY-MM-DD`（指定日）または `YYYY-MM`（その月の全日分）を入力
- 出力: `業務日報_YYYY-MM-DD.pdf`
- テンプレート: `テンプレート_日報` シート

#### カテゴリ別 月次サマリPDF（メニュー: 日報PDF → カテゴリ別 月次サマリPDF出力）
- 「設定」シート B1 セルに `YYYY-MM` を入力
- 出力: `業務日報_月次サマリ_YYYY-MM.pdf`
- テンプレート: `テンプレート_月次サマリ` シート（事前に作成必須）

##### 集計仕様
- **日数** … その実施業務がその月に報告されたユニーク日付の数
- **延べ人数** … (氏名 × 日付) のユニーク組み合わせ数（同じ人が10日関わったら10としてカウント）
- ポスト区分（L/S）は区別しない
- データ内のカテゴリで定義に無いものは「その他」へ集約

##### プレースホルダ
全体:
- `{{yearMonth}}` — 例: `令和8年4月`
- `{{totalDays}}` — 月内で報告があったユニーク日数
- `{{totalPersonDays}}` — 月内の (氏名 × 日付) 延べ数
- `{{totalPersons}}` — 月内に報告したユニーク氏名数
- `{{responsible}}` — 担当者

カテゴリ別（`days_<key>` / `persons_<key>`):

| key | カテゴリ |
|---|---|
| `incubation` | アートインキュベーションプログラム |
| `camp` | キャンプ |
| `showcase` | ショーケース |
| `workshop` | ワークショップ |
| `meetup` | ミートアップ |
| `lab` | ラボ運営および施設管理 |
| `other` | その他 |

例: `{{days_workshop}}`, `{{persons_workshop}}`

#### 請求項目別 月次サマリPDF（メニュー: 割り振り → 請求項目別 月次サマリPDF出力（クライアント送付用））
- 「設定」シート B1=`YYYY-MM`、B2=L繰越H（前月）、B3=S繰越H（前月）を入力
- 出力: `請求サマリ_YYYY-MM.pdf`
- テンプレート: `テンプレート_請求サマリ` シート（事前に作成必須）
- **用途**: CCBTへ送付するサマリー。4項目別の **延べ日数・延べ人数・金額** を表示する想定。L/Sポスト区分は外す方針

##### 集計仕様（L/S別の繰越方式）
「業務時間/8h=1ポスト」社内ルールに整合。1日が8時間を超える業務が多発するため、月単位で時間を集計→ポスト換算→端数は次月へ繰越、で精算する。

1. **当月実働H** = 割り振り台帳の L〜O 列を月で集計（L/S別）
2. **使用可能H** = 当月実働H + 前月繰越H（設定シートB2/B3より）
3. **みなしP** = `floor(使用可能H / 8)`（整数ポストに切り下げ）
4. **翌月繰越H** = 使用可能H − みなしP × 8（次月の B2/B3 に転記する）
5. **項目別配賦**: 各項目への金額按分は、みなしP を **当月実働の項目別時間比** で割り振り
6. **金額**: みなしP_L × 36,000 + みなしP_S × 29,400 → +消費税(10%) = 税込合計

##### プレースホルダ（テンプレート側で使う分だけ配置すればよい）
- 共通: `{{year_month}}`, `{{responsible}}`
- L/S精算: `{{hours_l/s}}`, `{{carry_in_l/s}}`, `{{avail_l/s}}`, `{{deemed_l/s}}`, `{{carry_out_l/s}}`
- 項目別 時間: `{{item1_total}}`〜`{{item4_total}}`, `{{itemN_hours_l}}`, `{{itemN_hours_s}}`, `{{grand_total}}`
- 項目別 延べ日数・延べ人数: `{{itemN_days}}`, `{{itemN_persons}}`, `{{total_days}}`, `{{total_persons}}`
- 項目別 按分P・金額: `{{itemN_posts_l}}`, `{{itemN_posts_s}}`, `{{itemN_posts}}`, `{{total_posts}}`, `{{itemN_amount}}`
- 集計金額: `{{subtotal_amount}}`, `{{tax_amount}}`, `{{grand_amount}}`

#### 請求集計シート（メニュー: 割り振り → 請求集計シートを更新（社内確認用））
- 「設定」シート B1=`YYYY-MM`、B2=L繰越H（前月）、B3=S繰越H（前月）→ メニュー実行
- 出力: `請求集計` シート（既存なら上書き）
- **用途**: 請求書本体は別途社内フォーマットで作成するため、その「数字の根拠」をスプレッドシートに表示しておくシート

##### 表示構成

**L/S別 ポスト精算**

| 区分 | 当月実働H | 前月繰越H | 使用可能H | みなしP | 翌月繰越H | 単価(円) | 金額(円) |
|---|---|---|---|---|---|---|---|
| L | … | … | … | (整数) | … | 36,000 | … |
| S | … | … | … | (整数) | … | 29,400 | … |
| | | | | 税抜小計 | … |
| | | | | 消費税(10%) | … |
| | | | | 税込合計 | … |

**翌月繰越** （★この値を次月の `設定` B2/B3 に転記）

**項目別 内訳（みなしPを当月実働時間比で按分）**

| 項目 | L時間(h) | L按分P | S時間(h) | S按分P | 金額計(円) | 延べ日数 | 延べ人数 |
|---|---|---|---|---|---|---|---|
| ①実施計画策定・全体管理 | … |
| ②機器運用 | … |
| ③設営管理・技術支援 | … |
| ④各事業におけるテクニカルマネジメント | … |

請求書を社内フォーマットで作成する際は、この `税込合計` または項目別 `金額計` を転記する。

##### 算出ロジック
1. 割り振り台帳の月内行から、L/S別×項目別の時間を集計
2. L/S別に: 当月実働H + 前月繰越H = 使用可能H → `floor(/8)` = みなしP → 余りが翌月繰越H
3. 項目別: みなしP_post × (item_post_hours / total_post_hours) で配賦
4. 金額: みなしP_L × 36,000 + みなしP_S × 29,400 → +消費税(10%)

### 4. 4請求項目への割り振り（割り振り台帳）

請求書の4項目（実施計画策定・全体管理／機器運用／設営管理・技術支援／各事業におけるテクニカルマネジメント）に各日報を時間配分するためのワークフロー。**arsaffix内部のみで運用**。業務従事者は関与しない。

#### 使い方
1. 管理用スプレッドシートのメニュー「**割り振り → #2 から最新データを取り込み**」を実行 → 「割り振り台帳」シートが自動生成され、最新の日報が追加される（増分のみ、重複なし）
2. 必要に応じて「**割り振り → 自動取り込みをON**」を実行 → 以降シートを開くたびに自動で取り込み（installable trigger）
3. 「割り振り台帳」シートの L〜O 列（4項目）に時間（h、0.25刻み）を入力
4. P列（配分計）= L+M+N+O、Q列（差異）= 勤務時間-配分計 が自動計算
5. 差異が0以外、または S ポストで項目1/4 に値が入った場合はセルが赤くなる（要修正）
6. 確認用に「**割り振り → 集計シートを作成/更新**」で `割り振り集計` シートを生成（月×4項目+合計、QUERYで自動反映）
7. 月末:
   - 社内確認用に「**割り振り → 請求集計シートを更新（社内確認用）**」で `請求集計` シートを更新（L/S別ポスト数・金額の明細）。請求書はここの数字を社内フォーマットに転記して作成
   - クライアント送付用に「**割り振り → 請求項目別 月次サマリPDF出力（クライアント送付用）**」で `請求サマリ_YYYY-MM.pdf` を生成

#### 割り振り集計シート（`割り振り集計`）
- 月ごとに `①実施計画 / ②機器運用 / ③設営・技術支援 / ④事業マネジメント / 合計` の時間を表示
- 中身は `=QUERY(...)` 1セルのみ。割り振り台帳の L〜O 列を編集すると即反映される
- 「集計シートを作成/更新」を再実行すれば数式が貼り直される（手で数式を消した場合のリセット用）

#### 列構成（割り振り台帳シート）

| 列 | 内容 | 入力 |
|---|---|---|
| A | タイムスタンプ（重複排除キー） | 自動 |
| B | 日付 | 自動 |
| C | 氏名 | 自動 |
| D | ポスト（L/S） | 自動 |
| E〜F | 開始 / 終了 | 自動 |
| G | 勤務時間 (h) | 自動 |
| H | イベント | 自動 |
| I | 実施事項 | 自動 |
| J | 業務内容 | 自動 |
| K | 特記事項 | 自動 |
| **L** | **①実施計画 (h)** ※L のみ | **手入力** |
| **M** | **②機器運用 (h)** ※L+S | **手入力** |
| **N** | **③設営・技術支援 (h)** ※L+S | **手入力** |
| **O** | **④事業マネジメント (h)** ※L のみ | **手入力** |
| P | 配分計 (=L+M+N+O) | 数式 |
| Q | 差異 (=G-P) | 数式（0以外で赤） |
| R | メモ | 任意 |

#### 制約バリデーション
- **差異≠0** → Q列が赤（時間配分が勤務時間と一致していない）
- **S ポスト × 項目1（L列）** → 該当セル赤（サポーターは①計上不可）
- **S ポスト × 項目4（O列）** → 該当セル赤（サポーターは④計上不可）

## スプレッドシートのカラム構成

| A | B | C | D | E | F | G | H | I | J | K |
|---|---|---|---|---|---|---|---|---|---|---|
| タイムスタンプ | 日付 | 氏名 | 開始時間 | 終了時間 | イベント名／実施業務 | 実施事項 | 業務内容 | 特記事項等 | 気づき・振り返り | 勤務時間 |

- F〜I列の内容はPDF（別紙6）に出力される
- J列（気づき・振り返り）はarsaffix内部用でPDFには含まれない
- K列（勤務時間）は開始・終了時間から自動算出（単位: 時間）
